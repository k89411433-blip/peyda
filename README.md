# پیدا — نسخه متصل به بک‌اند

این نسخه همان رابط React/Vite پروژه پیدا را نگه می‌دارد و APIهای Express + SQLite را به آن متصل می‌کند.

## اجرای محلی در ویندوز

### 1) نصب Node.js
Node.js نسخه 22 یا جدیدتر نصب باشد.

### 2) نصب وابستگی‌ها
داخل پوشه پروژه اجرا کنید:
```bash
npm install
```

### 3) اجرای بک‌اند
ترمینال اول:
```bash
npm run server
```
بک‌اند روی `http://localhost:3000` اجرا می‌شود.

### 4) اجرای ظاهر پروژه
ترمینال دوم:
```bash
npm run dev
```
سپس آدرس Vite که نمایش داده می‌شود را در مرورگر باز کنید.

در حالت توسعه، درخواست‌های `/api/*` خودکار به Express روی پورت 3000 فرستاده می‌شوند.

## نسخه انتشار

```bash
npm run build
npm start
```

Express فایل‌های ساخته‌شده در `dist` و APIهای `/api/*` را از یک سرور ارائه می‌کند.
